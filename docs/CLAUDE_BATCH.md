# Bounded Claude draft-case batch

`node scripts/claude-batch.mjs` prints a no-network plan. The initial batch uses
48 unreviewed synthetic cases across three locales, four age bands and input/output
assessment. Output cases are authored text submitted for classification, **not
answers generated by a live model**. This does not test the full generation or
Koda delivery pipeline. Translated cases are correlated; the set is not held out.

The runner sends only text, stage and trusted profile, never expected labels or
case metadata. Reports preserve IDs and assessment metadata, fixed summary slices
and digests; no raw prompts, provider prose, credentials or exception details.
See [BATCH_REPORT.md](BATCH_REPORT.md) for denominator and missing-case behavior.

## Shared budget and billing prerequisites

The existing authorization is USD 10 total for this first evaluation, not a new
USD 10 per script. The first run reserves 387,840 micro-USD. The 48-call batch
reserves 6,205,440 micro-USD with conservative planning assumptions, for a combined
USD 6.59328 before any higher prior billed cost. These reserves are not invoices
or guaranteed provider billing enforcement. Pricing assumptions expire after
seven days from November 9, 2026. No retries or alternative providers are used.

Live execution requires `ANTHROPIC_API_KEY`, a clean committed checkout, the exact
original smoke report, and a private `reports/private/claude-billing.json` record.
An accountable operator must create that record from the evaluation key's cost
page after its **data-as-of timestamp covers the smoke run**. Observing a stale
page after the run is insufficient. The Console was checked after the smoke run:
its data-as-of was November 9, 7:34 AM UTC, before the report's 8:28 AM UTC
completion. The displayed USD 0.00 is therefore not reconciliation. No valid
billing record has been created and no batch calls have run.

Billing record fields (all required; no extra fields):

- `schemaVersion`: integer 1.
- `source`: `claude-console-key-cost`.
- `smokeReportSha256`: the original report SHA-256 in CLAUDE_SMOKE_RESULT.md.
- `dataAsOf`: actual provider reporting coverage, UTC ISO with milliseconds.
- `observedAt`: actual observation timestamp in the same format.
- `totalCostUpperBoundMicroUsd`: nonnegative integer upper bound for all observed
  charges on the dedicated evaluation key. If the display rounds to cents, add
  at least one cent (10,000 micro-USD) to the displayed amount; do not assert zero
  from a rounded zero display. Include other use of the same key if any.

The validator checks timestamps, binding, freshness and arithmetic only; it cannot
prove that someone copied a truthful dashboard value. Records are accepted for
24 hours from observation. Prior budget reservation is never reduced below the
original smoke reserve. Evidence and credentials stay private and ignored by Git.

`--execute` creates an exclusive reservation before the first possible call and
does not reset it after errors. Partial reports are saved after every case. The
runner stops on an unavailable assessment, and exits nonzero on an incomplete run
or exact draft-label mismatch. These exit codes are regression signals, not
release approvals. Do not delete the reservation to retry; reconcile charges and
review the failure first. Public child traffic remains prohibited by pending
release gates.

The sequential evaluation loop is independently tested with mock callbacks.
It snapshots fixture inputs, transmits no expected labels, checkpoints before
the first call and after each result, and makes no further call after persistence
failure. Adapter exceptions/malformed assessments become metadata-only failures
and stop the batch. Caller cancellation suppresses a late assessment; the actual
Claude adapter supplies its own bounded deadline. These are orchestration tests,
not paid model observations. Rechecking the Console still showed data as of
7:34 AM UTC, predating the smoke run; no reconciliation was fabricated.
